## Overview
A machine-learning project covering data validation, regression, classification, clustering, model evaluation, and a FastAPI prediction service.

## Project Structure
- data/ - Dataset
- src/ - Source code
- tests/ - Automated tests
- models/ - Saved machine-learning models
- artifacts/ - Evaluation reports and metrics
- plots/ - Generated plots
- samples/ - Sample files
- docs/ - Assignment documentation

## Models
- Regression: Linear Regression
- Classification: Logistic Regression
- Clustering: K-Means with k=2
